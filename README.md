# DV Легион

Первая версия корпоративного сайта: дистрибуция и оптовые поставки.

## Структура
- dist/index.html — содержание
- dist/style.css — адаптивный дизайн

## Локальный просмотр
Запустите `python3 -m http.server 8080 --directory dist` и откройте http://localhost:8080. Сборка и внешние зависимости не требуются.

## Перед публичным запуском
Уточнить фактический ассортимент и географию поставок. Согласовать содержание алкогольного раздела. Формы, интернет-магазин, оплата и вымышленные контактные данные не добавлены.

## Дальнейшее развитие
Фактический каталог для B2B, обращения клиентов с выбранным каналом доставки, отдельные страницы услуг — после согласования требований.

## Источник сведений о компании
Контакты, адреса, банковские реквизиты и период лицензии перенесены из «ДВ Легион ООО карточка основных сведений (ВТБ).docx», предоставленной 04.09.2026. Проверка текущего статуса лицензии по реестру не выполнялась. Бухгалтерские отчёты не входят в сайт. Кнопки обращения открывают почтовую программу пользователя; серверной отправки нет.

## Каталог
954 товарные позиции извлечены из колонки «Номенклатура» ОСВ по счёту 41 за первое полугодие 2026 года (загружена 26.08.2026). Строки счетов и итогов исключены. Исходные коды и названия сохранены; одинаковые названия с разными кодами остаются отдельными позициями. Категории определены по наименованию. catalog-data.json содержит только code, name, category, без финансовых сумм и количеств. Текущее наличие и цены не заявлены.

## Обновление направления сайта
Удалены раздел перевозок, транспортные ссылки, тексты и изображение терминала. Все 954 товарные позиции и 14 категорий сохранены. Добавлены 61 проверенная фотография из открытых каталогов; источники находятся в docs/product-image-sources.json. Остальные позиции показываются без фотографии. Изображения встроены в данные каталога для независимости от внешних серверов.
