# DV Легион

Первая версия корпоративного сайта: оптовая дистрибуция алкогольной продукции и грузовые перевозки.

## Структура
- dist/index.html — содержание
- dist/style.css — адаптивный дизайн
- dist/port.jpg — иллюстративная фотография терминала, Unsplash: https://images.unsplash.com/photo-1494412519320-aa613dfb7738, https://unsplash.com/license

## Локальный просмотр
Запустите `python3 -m http.server 8080 --directory dist` и откройте http://localhost:8080. Сборка и внешние зависимости не требуются.

## Перед публичным запуском
Добавить подтверждённые корпоративные контакты, реквизиты и сведения о лицензии. Уточнить фактический ассортимент и географию поставок. Согласовать содержание алкогольного раздела. Формы, интернет-магазин, оплата и вымышленные контактные данные не добавлены. Фотография терминала иллюстративная, не утверждает принадлежность объектов компании.

## Дальнейшее развитие
Фактический каталог для B2B, обращения клиентов с выбранным каналом доставки, отдельные страницы услуг — после согласования требований.
