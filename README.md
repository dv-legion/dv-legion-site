# DV Легион — корпоративный B2B-сайт

Премиальный корпоративный сайт ООО «ДВ Легион», посвящённый только дистрибуции алкогольной продукции и оптовому сотрудничеству.

## Что входит
- премиальная адаптивная главная страница;
- B2B-каталог с фильтрацией по категориям и поиском;
- 954 позиции исходной номенклатуры;
- фотографии товаров, где они были подтверждены;
- динамические изображения категорий;
- форма обращения партнёра через подготовленное письмо на info@dv-legion.ru;
- мобильное меню;
- реквизиты и контакты компании;
- robots.txt, sitemap.xml и брендированная страница 404.

## Структура
- dist/index.html — главная;
- dist/catalog.html — каталог;
- dist/style.css — единая дизайн-система и адаптив;
- dist/site.js — мобильное меню и B2B-форма;
- dist/home.js — изображения категорий;
- dist/catalog.js — фильтрация, поиск, пагинация;
- dist/catalog-data.json — данные каталога;
- dist/404.html — страница 404.

## Локальный просмотр
`python3 -m http.server 8095 --directory dist`

## Сервер dev01
Рабочая копия размещена в:
`/srv/projects/dv-legion-site/dist`

Тестовый просмотр на самом сервере:
`http://127.0.0.1:8095/`

## Публичный запуск
Домен dv-legion.ru должен быть направлен на production-сервер, после чего сайт необходимо отдать через HTTPS на 80/443. На момент подготовки этой версии DNS домена ещё указывал на старый хостинг, поэтому DNS автоматически не менялся.

## Важно
Сайт является B2B-каталогом. Розничная продажа и оплата алкогольной продукции на сайте не реализованы. Наличие, цены и условия поставок подтверждаются менеджером компании.
